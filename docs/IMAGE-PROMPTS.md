# Book My Charter — image prompts for ChatGPT

## How to use

1. Open a new ChatGPT chat. Paste the **Style block** below as the first message.
2. Then paste one prompt at a time. Pick the size shown for each: **Landscape (1536×1024)** or **Portrait (1024×1536)**. These are ChatGPT's largest sizes. I crop and resize for each slot on the site, so keep the framing notes.
3. **Do not upload the logo for these images.** A logo painted on an aircraft tells visitors "this is our aircraft". The site can't say that until the AOC/permit and registrations are confirmed. AI tools also often distort logos. The logo stays in the header, and I add it in code to the social-share image.
4. Download each result and save it under exactly the file name given, in `assets-incoming/images/`. Then send them to me.
5. On the site, each image will be marked as an illustration (alt text "Illustration: …"). Photos of specific aircraft types still come from the Wikimedia Commons process.

If a result has any text, a registration, an airline livery, the wrong number of engines or rotor blades, or melted details, reply: *"Regenerate. Fix: [the problem]. Keep everything else identical."*

## Style block (paste once, first)

```
You are generating ultra-realistic photographs for a premium private aviation charter company in India. Every image in this chat must follow these rules:

PHOTOREALISM: Indistinguishable from a professional aviation photograph. Shot on a full-frame camera, natural lens perspective, correct physical lighting, accurate reflections on glossy paint, visible micro-detail: panel lines, rivets, pitot tubes, static wicks, antenna fins, tyre tread, window seals, rotor-blade tips, heat shimmer near engines where running. No CGI look, no plastic surfaces, no over-smoothing, no HDR halos.

AIRCRAFT: Generic modern aircraft of the stated class, not a specific branded model. Plain gloss-white paint with a thin, subtle dark-navy cheat line only. Mechanically correct: right number of engines, wheels, propeller blades or rotor blades; symmetric wings; correct proportions; landing gear touching the ground properly.

STRICTLY NONE OF: text, letters, numbers, registration marks, airline or operator livery, logos, flags, watermarks, signage with readable words, identifiable faces, brand names.

COLOUR & MOOD: Clean, calm, premium. Natural colours with a cool grade: deep navy shadows, soft sky-blue highlights, warm sunlight only where the scene calls for it. Uncluttered compositions with generous negative space. India-appropriate settings without identifiable landmarks.

Reply only with the image.
```
