# Aircraft type images: ChatGPT prompts

52 prompts, one per aircraft type, so every card and every aircraft page shows its own aircraft instead of a repeated class picture.

## How to use

1. In ChatGPT, open a new chat for each aircraft (one image per chat keeps it accurate).
2. For accuracy, first attach one real photo of that exact type: its Wikipedia page's main photo is ideal. The prompt tells ChatGPT to copy only the shape from it.
3. Paste the prompt, generate, and check the result against the "Check" line under it. Regenerate if any item is wrong.
4. Download it as PNG and name it exactly with the file name shown, e.g. `airbus-h125.png`.
5. Put all files in `assets-incoming/aircraft-types/` and tell me. Any number at a time is fine: types without a file keep their current picture.

## Rules every image follows

- One real aircraft type, accurately drawn. Plain white livery with a thin navy and blue stripe (the site's colours). No text, logos, operator branding or registration marks.
- Same camera angle for all: three-quarter front, nose to the left, whole aircraft in frame, centre slightly right, top 12% and bottom 20% clear for the card labels.
- Landscape 3:2, 1536 × 1024. I resize them for the web.
- The site labels them as illustrations of the type, not photos of an aircraft offered for charter.

## Check before sending (every image)

- Engine count and position, tail type, wing shape, landing gear and rotor or propeller blade count match the "Check" line.
- No text anywhere, including on the tail and under the wing.
- Nothing cropped: wingtips, tail, rotor tips all inside the frame.
